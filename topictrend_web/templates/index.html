About Topic Trends

Topic Trends is a high-performance Wikipedia analytics engine that provides insights into pageview patterns and editing activity across Wikipedia categories and articles.

Features

  • Pageview Trends: Track and visualize pageview trends for categories and articles over time
  • Page Edit Trends: Monitor editing activity patterns across Wikipedia content
  • Pageview Delta & Page Edit Delta: Compare pageview and edit metrics between different time periods
  • Category Search: Navigate Wikipedia's category hierarchy and analyze topic trends
  • Multi-Wiki Support: Analyze data across multiple Wikipedia language editions

Technology

Built with Rust for high-performance data processing, Topic Trends uses efficient algorithms and data structures to handle large-scale Wikipedia analytics. The web interface follows the Wikimedia Codex design system for a consistent user experience.

Data Sources

All data is sourced from publicly available Wikipedia dumps and pageview statistics, processed and aggregated to provide meaningful insights into Wikipedia usage patterns.
